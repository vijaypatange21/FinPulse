# FinPulse

FinPulse now contains both:

- frontend: React + Vite application
- backend: Django REST API with schema-inspired data models and 5 ML prediction endpoints

## Project Structure

- frontend
- backend

## Backend Quick Start

1. Go to backend folder.
2. Install dependencies from requirements.txt.
3. Copy .env.example to .env.
4. Run migrations.
5. Start server.

Detailed backend docs: backend/README.md
